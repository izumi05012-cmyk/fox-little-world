# 小窝首页：融入窗景

在现有小窝首页上调整，沿用原来的实时窗景、天气、照片、聊天和贴纸本。

## 设计

- 去掉整页不透明纸底，让背景山景、星空、雨雪透出来。
- 内容分成局部磨砂面板；白天用浅色玻璃，夜晚和雨天用深色玻璃与暖白文字。
- 照片、胶带和人物贴纸保留实体感，搭配蓝、粉、紫、草绿的小点缀。
- 顶栏和欢迎区之间留出一段完整窗景；页尾“收起页面，只看风景”可隐藏内容，再点“回到小窝”恢复。
- 手机单列、电脑双列，原有天气选择、更换照片及长按心跳继续可用。

## 功能

首页增加已有信箱、拉钩本、请帖的直接入口。由首页打开，返回首页；从贴纸本打开，仍返回贴纸本。“记下今天”复用现有回忆页。尚未实现的日记入口标注“筹备中”。

照片继续使用原有 IndexedDB 和照片槽位；天气偏好、回忆仍使用原来的本机存储。自定义窗景沿用原来的规则，仅在雨雪场景显示。

## 运行与验收

```sh
npm ci
npm run dev
```

浏览器验收：

```sh
npx playwright install chromium
npm run test:home
```

系统已有 Chromium 时会优先使用 `/usr/bin/chromium`，也可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定。测试运行生产构建，隔离浏览器数据，并模拟天气及远端聊天接口，不发送真实消息或信件。测试记录在 `verification.json`，效果图由同一脚本生成。

- `mobile.png`：手机白天
- `mobile-details.png`：手机照片墙及日子
- `desktop.png`：电脑白天
- `night-mobile.png`：手机夜晚
- `scenery-only.png`：收起页面后的窗景

本分支供预览验收，未合并或发布。
